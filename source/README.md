# StallGuard 可维护源码

这是从 v0.2.2 交付程序恢复并持续维护的源码工程。恢复过程与版本演进见工作区根目录的 `项目历史.md`。

## 开发运行

```powershell
cd source
python -m pip install -r requirements.txt
python app.py
```

正常流程为：选择“初始化标定”并载入已知正常数据段；程序冻结当前机器判据的基线，然后监听 `127.0.0.1:8765`。另开终端运行：

```powershell
python simulate_sensor.py ..\data\pressure_timestep.csv --start-step 88000 --rate 20
```

`--rate` 是传入速度（行/秒），设为 `0` 表示不限速；`--batch-size` 控制每条 TCP 消息包含的行数。

打包后的 `SensorSimulator.exe` 双击会打开图形界面，可选择任意兼容CSV并设置响应输出间隔、目标地址、发送速度、批量行数和时间步范围。带命令行参数启动时仍进入原来的脚本模式，因此 `run_simulator.ps1` 保持兼容。

## 验证与打包

```powershell
python run_tests.py
.\build.ps1
```

打包结果写入 `source\dist\<构建时间>`。每次使用独立构建目录，避免 Windows 正在扫描旧缓存时阻塞下一次构建；也可用 `-BuildTag my_version` 指定目录名。正式归档时仅保留最新构建，并删除 `source\build` 中间产物。

## 检查逐渐关阀时是否误报

用稳定正常段建立基线，再让另一段正常变工况数据离线通过同一判据：

```powershell
python validate_baseline.py normal_steady.csv normal_throttle_sweep.csv --method autocorrelation
```

如果已知真正失速开始的累计时间步，可追加 `--known-stall-step 105000`。程序会单独统计该时间步之前的报警窗口；返回码 `2` 表示存在失速前报警，需要重新评估阈值、窗口或多工况基线。

## 设计约束

- 初始化数据必须是同一测量链路下的已知正常工况，且探针名称、顺序、输出间隔及滤波设置与在线阶段一致。
- 小波图供人工观察；红绿灯只跟随当前选择的“时序自相关”或“数据熵”机器判据。
- 系统报警采用 K-of-N、连续触发窗口和连续解除窗口，避免单点毛刺。
- 在线首个样本的物理时间固定为 `0 s`。
- 小波图默认只计算并显示当前分析窗；可选择保留当前窗及最多两个紧邻窗口。左侧“探针”下拉框切换后立即对选中周向探针重算小波图。
- CSV第一列作为累计时间步，其余数值列均动态识别为探针；程序没有写死探针数量，但计算、内存和绘图成本随探针数近似线性增加。
- 默认分析窗口重叠率为 `50%`。数据接收与绘图解耦，界面约以 15 FPS 刷新；RMS 和判据图只处理当前可见时间段，小波只在对应页可见时以较低频率更新。机器判据仍逐窗计算，不因绘图限帧而漏判。

## 16通道主动控制接口

主界面右下角提供16个等角度动作机构。1号位于环形图正上方 `0°`，编号沿顺时针方向增加，每个通道可独立设置输出使能和待机偏角。为了避免未经确认的硬件动作，程序启动时16个通道默认全部关闭；演示时可点击“全部开启”。

系统通过探针报警上升沿定位失速团：相邻探针先后报警时，由周向角差和时间差估计旋转角速度，再外推当前位置；探针同窗报警、无法得到有效时间差时，退化为当前探针风险的周向重心。进入系统报警后，离预测位置最近的两个已使能动作机构自动转向目标并输出。喷气采用可调物理时间脉冲，默认 `100 ms`；每个脉冲结束时使用最新估计重新定位、重新选择通道并发出下一脉冲。报警解除立即撤销输出，不等待当前脉冲结束。

当前定位还使用初始化段建立的逐探针压力基线：无法得到有效报警时差时，根据短时压力相对基线及周向中位值的差异计算周向重心。报警期间每个新分析窗都会更新目标角和最近通道，不再把喷口方向冻结到脉冲结束；TCP数据结束或断开时立即撤销全部输出。

动作机构使用静态红色动作指示和静态喷气短线，不再闪烁。右下角使用“控制 / 动作记录”标签页，环形控制与16通道统计不会同时挤占空间。16个通道分别记录启动喷气次数：通道从未动作变为动作时加1，同一连续动作期间仅改变喷口角度不重复计数；数据结束保留统计，新监听会话开始时清零。

硬件层通过 `src.actuation.ActuatorController` 解耦。可按通道注册回调：

```python
window.actuator_controller.register_channel_output(1, channel_1_writer)
```

也可注册整帧PLC/网络适配器：

```python
window.actuator_controller.register_frame_output(plc_adapter.send)
```

每条命令包含通道号、通道周向角、使能状态、动作状态、喷口偏角、预测目标角、物理时间和定位置信度。未确定真实PLC、串口或现场总线协议前，交付程序只执行软件回调和界面动画，不应宣称已完成物理控制闭环。导出监听结果时会同时生成后缀为 `_actuation.csv` 的动作指令日志。
